Voltage Drop

Effective-impedance voltage drop using NEC Chapter 9, Table 9 a.c. resistance and reactance — Ze = R·cosθ + X·sinθ.

Circuit Inputs

System & Load
Nominal system voltage the percentage is taken against. For three-phase this is the line-to-line voltage; for single-phase it is the voltage across the load (e.g. 120 or 240).
Load displacement power factor, 0–1. Drives the angle θ in Ze = R·cosθ + X·sinθ. Use 1.0 for a purely resistive load (heating, incandescent). Lagging is the normal case; choose leading only for a net-capacitive load, which subtracts the reactive term.
One-way run length from source to load. The return path is accounted for by the 2 (single-phase) or √3 (three-phase) multiplier — don't double it yourself.
Conductor — NEC Ch. 9 Table 9
Largest size used for one conductor per phase. When the conductor size above is larger than this, the run is split into equal parallel sets of this size and the per-phase R and X are divided by the set count. NEC 310.10(H)(1) permits paralleling only 1/0 AWG and larger.

Suggested as aluminum once the load current reaches 100 A (common practice for larger feeders/services) and copper below that, until you choose one.
Selects the Table 9 column. PVC and aluminum conduit share the same reactance; steel conduit has a higher reactance and a slightly different a.c. resistance from magnetic effects. Use PVC / nonmetallic for RNC, HDPE, or direct-buried.
Acceptance Target
Pass/fail threshold only. The NEC states voltage-drop limits as recommendations in Informational Notes (210.19(A) and 215.2(A)): about 3% on a branch circuit or feeder, and 5% total for feeder plus branch circuit. Not an enforceable rule unless a project spec or other code adopts it.
