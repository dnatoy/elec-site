Elevator Branch-Circuit Sizing

Branch-circuit conductor and short-circuit/ground-fault protection sizing for a single elevator driving machine, from manufacturer nameplate/submittal data, per NEC 620.13 and Article 430, Part IV.

Elevator Inputs

Nameplate / Submittal Data — NEC 620.13

Driving machines are almost always three-phase; single-phase is available for the rare small/residential lift.

Reference only — conductor and OCPD sizing below use the submittal's Running Current directly, not a voltage-based table lookup.

Include cab lighting, ventilation, and controller loads here if the submittal breaks them out separately from the driving-machine Running Current. Per NEC 620.13(D), this is added to the conductor's minimum ampacity at its full value alongside the motor's own contribution — leave at 0 if the Running Current already represents the entire branch-circuit load.
Branch-Circuit Protection — NEC 430.52
Only use this if the base Table 430.52 rating won't allow the elevator to start reliably — an engineering judgment call, not a default. The increased rating is a hard ceiling (rounds down to the nearest standard size, not up). Check the manufacturer's submittal first: a stated maximum OCPD rating governs over this tool either way.

Affects only the Maximum (430.52) figure below — the Recommended figure is unaffected.

Instantaneous-trip breakers (MCPs) have no 430.52(C)(1) Exception No. 2 allowance — field adjustment follows the 430.52(C)(3) trial-setting procedure instead.

Only use this if the field genuinely needs a rating other than Recommended — e.g. to hold a downstream rating down (one standard size lower), or add starting headroom up to the Maximum (430.52) ceiling above, without necessarily invoking Exception No. 2 by name. Affects only the equipment grounding conductor and schedule notation below — the Recommended and Maximum figures stay as computed, unaffected. Going lower is capped at a hard floor: the smallest standard rating that still carries the elevator's own raw Running Current (not the 175%- inflated Recommended figure).

No standard rating differs from Recommended within the floor-to-Maximum range — Recommended is the only workable MOCP rating here.

Ampacity Basis — NEC 310.16
Suggested as aluminum once the OCPD actually protecting the circuit (Recommended, or the Exception No. 2 rating when that override is checked) reaches 100 A, unless you choose otherwise.
Raceway & Fill
Line conductors only. Defaults to 2 for single-phase, 3 for three-phase. Excludes the equipment grounding conductor, added separately below.
